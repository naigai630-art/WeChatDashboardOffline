微信通话统计修复补丁

安装方法

1. 关闭正在运行的离线看板程序。
2. 打开原来的 WeChatDashboardOffline 项目文件夹。
3. 将本补丁 ZIP 直接解压到该项目文件夹。
4. Windows 询问是否覆盖文件时，选择全部替换。
5. 再次双击 run_offline.bat。

补丁会替换以下两个文件：

tools\build_stats.py
offline\third_party\wechatauto-replica\wechatauto\db.py

修复内容

1. 同时读取 message_content 和 compress_content。
2. 支持微信 4.x 复合通话类型码。
3. 支持 XML、转义 XML、JSON、中文时长和时分秒格式。
4. 修复接通次数、累计时长和最长通话统计。

本补丁不包含聊天记录、数据库、账号标识或密钥。
